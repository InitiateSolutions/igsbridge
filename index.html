Bridge Connect™

A Modern Bridge for Legacy MUMPS Data

Bridge Connect™ is a Change Data Capture (CDC) system—the secure connectivity backbone that allows legacy MUMPS systems to participate in modern, real-time data and clinical workflows—without disruption. Unlike traditional ETL or batch-driven solutions, this approach keeps data synchronized as it changes—without heavy replication, downtime, or complex reprocessing cycles. Idempotent processing ensures data consistency even during retries or interruptions.

Near Real-Time Data Access

Pulls and detects changes to live data without impacting the live transactional system.

Idempotent Processing

Ensures data consistency even during network interruptions or retries

Instant Metadata Awareness

Detects schema changes automatically and manages versions.

Built by Legacy Experts

Deep knowledge of correct globals, files, and fields

— S/03 / Packages Training Packages

Tiered enablement, aligned to deployment scope.

Each package includes a set number of base courses — from one in Bronze up to four in Cobalt — with a recorded session for every included course. Live delivery follows recommended cohort sizes by course type; additional instruction is available as ad hoc training on a per-course or hourly basis.

— TIER 01 / Bronze

Bronze

A streamlined entry point for foundational training. Best for teams seeking initial orientation, targeted role familiarization, or a low-overhead option tied directly to the products they have purchased.

  • One included base course
  • One recorded session per included course
  • Cohort sizes per training type
  • Ad hoc training available separately
— TIER 02 / Silver

Silver

Expanded training coverage aligned to licensed IGS Bridge™ products. Designed for organizations strengthening user adoption and targeted technical capability in direct proportion to the components they are implementing.

  • One included base course
  • One recorded session per included course
  • Supplemental per-course or hourly add-ons
  • Recommended cohort sizes preserved
— TIER 03 / Gold

Gold

Recommended

The recommended option for broader platform deployments. Provides comprehensive standard training aligned to licensed products — ideal for organizations seeking strong implementation readiness across multiple IGS Bridge™ tools.

  • Two included base courses
  • One recorded session per included course
  • Role-based sessions across multiple tools
  • Add-on refreshers per-course or hourly
— TIER 04 / Cobalt

Cobalt

Advanced, organization-specific enablement for complex implementations or long-term transformation efforts. Best for enterprises that require deeper operational coaching and broader adoption support.

  • Four included base courses
  • One recorded session per included course
  • Custom workshops & train-the-trainer (ad hoc)
  • Onsite mentoring & expanded enablement (ad hoc)
